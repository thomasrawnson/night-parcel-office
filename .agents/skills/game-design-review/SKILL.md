# Game Design Review

Review proposals against the approved roadmap before implementation. Do not assume a proposed feature should be built.

Assess:

- player understanding and gameplay clarity;
- meaningful decisions, difficulty progression, and cognitive load;
- feedback, consequences, engagement, retention, and replayability;
- mobile usability;
- implementation complexity and feature necessity;
- alignment with the current approved roadmap milestone.

Prefer the smallest change that improves the player's experience. Challenge complexity, content volume, or systems work that does not strengthen the core sorting loop. Do not treat speculative engagement gains as evidence.

## Output

Report:

- Gameplay objective
- Expected player experience
- Potential design problems
- Simplest viable implementation
- Acceptance criteria
- Playtesting recommendations
- Final recommendation: `IMPLEMENT`, `SIMPLIFY`, `DEFER`, or `REJECT`

State assumptions and distinguish automated validation from human playtesting.
