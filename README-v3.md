# Night Parcel Office — Prototype v3

Drop-in update for the existing browser prototype.

## What's changed

- 6 parcels retained, with more visual personality.
- Regulations simplified to three large IF → THEN cards.
- Parcel routing is now physical:
  - DELIVER drops down the desk.
  - RETURN shoots left.
  - QUARANTINE shoots toward the cage.
- Flip actually flips between front and back information.
- Poke causes parcel reactions.
- Mr Nibbles can poke back and appear in the quarantine cage.
- Cursed mirror remains, but its consequence is more visual.
- Added desk props and a frosted office window.
- Final parcel reveals a silhouette and reacts to listening/poking.
- More absurd labels and less explanatory copy.

## Run

Open `index.html` directly, or from the repo:

```bash
cd ~/Developer/night-parcel-office
open index.html
```

If using the local server:

```bash
cd ~/Developer/night-parcel-office
python3 -m http.server 8010
```

Then open http://localhost:8010
